# Tetris-opening-practice

`tetris.html` 하나로 동작하는 테트리스입니다. 빌드 없이 브라우저로 파일을 열면 실행됩니다.

## 코드 구조

스크립트는 `// ---------- 구간 ----------` 주석으로 나뉘어 있습니다.

- **state**: 게임 상태는 모두 객체 `G` 하나에 들어 있습니다 (보드, 대기열, 현재 블록, 홀드, 점수 등).
  `structuredClone(G)`로 저장하고 `G = 저장본`으로 복원할 수 있어, 되돌리기나 재시도에 그대로 쓸 수 있습니다.
- **modes**: 모드마다 객체 하나를 `MODES`에 정의합니다. 엔진은 아래 훅만 호출하고 모드 이름으로 분기하지 않습니다.

| 훅 | 역할 |
|---|---|
| `name`, `desc()` | 메뉴에 표시할 이름과 설명 |
| `setup(G)` | (선택) 첫 블록 전에 보드나 대기열 준비 |
| `nextBag(G)` | 대기열이 모자랄 때 뒤에 붙일 블록 배열 |
| `gravity(G)` | 중력 (ms당 칸 수) |
| `afterLock(G)` | (선택) 블록 고정과 점수 계산 후 호출. `'win'` 또는 `'lose'`를 반환하면 게임 종료, `'next'`면 바로 새 판 시작 |
| `stats` | 옆 패널 항목 `[이름, 값(G), 강조?]` |
| `recordBest(G, won)` | 최고 기록 갱신, 새 기록이면 `true` |
| `result(G, won)` | 결과 화면 항목 `[이름, 값, 강조]` (강조: `true`는 큰 숫자, `'note'`는 문장) |
| `title(won)` | (선택) 결과 화면 제목 |
| `practice` | (선택) `true`면 되돌리기(⌫), 같은 순서로 다시(R), 새 순서(N) 사용 |

새 모드는 `MODES`에 항목을 하나 추가하면 메뉴에 자동으로 나타납니다.

## 연습 모드

- **DPC 연습**: SDPC 같은 8줄 PC 루프가 끝난 직후 상황입니다. 빈 보드에서 시작하고, hold에 남은 블록 1개가 들어 있으며, 4·5가방이 이어집니다.
  15블록 안에 퍼펙트 클리어(6줄)를 하면 성공이고, 바로 다음 판이 시작됩니다.
  남은 줄 수로 정리할 수 없는 모양이 되거나 15블록을 다 놓으면 실패입니다.
  - 셋업은 [Hard Drop 위키 DPC Setups](https://harddrop.com/wiki/DPC_Setups)의 기본 셋업(11개, 반전 포함 22개 변형)입니다.
    hold와 블록 순서를 보고, 이 게임의 회전 규칙으로 실제로 완성할 수 있는 셋업을 탐색해서 고릅니다.
    hold 7종 × 4가방 순서 5,040가지 모두에서 셋업이 하나 이상 성립합니다(위키의 "100%"와 일치).
  - **DPC 연습 설정**: hold 후보(기본 O·S·Z·I, J·L·T는 선택), 목표 위치 표시, 배치 판정(목표와 다르면 실패)을 켜고 끌 수 있습니다.
  - 목표는 빌드 → T-스핀 → PC 순서로 표시됩니다. PC 단계 목표는 다음 우선순위로 고릅니다.
    1. 그 순서로 가능한 **T-스핀 해법**(T-스핀 트리플 > 더블 > 싱글, 일반 > 미니). 위키처럼 T-스핀 미니 싱글은 제외합니다.
    2. 셋업의 **최소해법**: 5가방 순서 5,040가지 전부를 덮는 가장 작은 해법 묶음(셋업당 1~6개)입니다. 미리 계산해 `DPC_SETUPS`의 `pc`에 넣어 두었습니다.
    3. 그 밖의 해법. 판정은 5가방 7개로 만든 올바른 퍼펙트 클리어를 모두 인정합니다.
  - PC는 루프를 위해 5가방 7개만 씁니다. 마지막 한 개는 6가방 첫 블록과 hold를 바꿔서 놓고, 그 6가방 블록이 다음 루프의 hold 블록이 됩니다.
  - 계산한 T-스핀 확률이 위키의 "T-Spin Chance"와 7개 셋업 모두 일치합니다.
  - 상단에 지금 따라가는 셋업 이름이 표시되고, 반전 셋업이면 READY 화면에 MIRROR가 뜹니다.
- 각 판은 처음 결과만 성공률에 집계됩니다. 실패한 뒤 되돌리기나 같은 순서로 다시 해서 성공해도 성공률은 오르지 않습니다.
- **좌우 반전** (조작감 설정 → 좌우 반전): 끔 / 켬 / 판마다 무작위. 연습 모드의 시작 보드와 정해진 hold 블록을 뒤집고(L↔J, S↔Z), 블록 순서는 그대로 무작위입니다.
  반전된 판은 READY 화면의 MIRROR와 상단의 "좌우 반전" 표시로 알려 줍니다. DPC처럼 빈 보드에서 시작하는 연습은 보드가 달라지지 않으므로, 이 표시를 보고 반전 빌드로 쌓으면 됩니다.
  판의 반전 여부는 `G.mirror`에 저장되고, 같은 순서로 다시(R)를 해도 유지됩니다. 반전에는 `mirrorRows` / `mirrorPiece`를 씁니다.
- 회전은 TETR.IO의 SRS+ 킥 표(I 블록 대칭 킥, 180° 킥 포함)를 씁니다.
- 연습 모드는 `pcDrill({...})`로 만듭니다. `board`에 fumen 문자열(v115)을 주면 그 보드에서 시작합니다.

## fumen

`decodeFumen(문자열)`은 fumen(v115) 링크나 문자열을 페이지 배열로 바꿉니다.
각 페이지의 `field`는 보드와 같은 23줄(위→아래) 배열이고, 페이지에 놓인 블록은 `piece`와 `placed`에 들어 있습니다.
